# Fichas de Avaliação 2026

Site acessível para preencher as Fichas de Avaliação do Educando falando ou escrevendo sobre o aluno. A ficha sai em Word, no formato de sempre.

Este arquivo é uma cópia do artefato publicado no Claude. Recursos como salvar na conta, ditado, voz e download usam serviços do artefato e podem não funcionar ao abrir o `index.html` direto (não foi testado fora do Claude).
